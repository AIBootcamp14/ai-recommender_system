## 주요 발견사항

### 1. Latent Factor 수 (num_factor)
- **낮은 값(32)이 가장 좋은 성능**을 보임
- 128 → 48 → 32로 줄일수록 성능 향상
- 과적합 방지 효과로 추정

```
num_factor 128: NDCG ≈ 0.0198
num_factor 48:  NDCG ≈ 0.0204-0.0206
num_factor 32:  NDCG = 0.0215 ✓
```

### 2. Alpha (Confidence 가중치)
- **낮은 값(7-8)이 효과적**
- 높은 alpha(36-37)는 성능 저하
- implicit feedback에서 과도한 confidence는 역효과

```
alpha 7:  NDCG = 0.0215 ✓
alpha 8:  NDCG = 0.0206
alpha 36: NDCG = 0.0196
```

### 3. Regularization
- 0.02 근처가 최적
- 너무 낮거나(0.001) 높으면(0.037) 성능 저하

### 4. Iterations
- **10회로 충분** (더 많은 iteration이 항상 좋은 것은 아님)
- 학습 시간 절약 효과

## 결론 및 향후 개선 방향

### 결론
- **낮은 num_factor(32)와 낮은 alpha(7)** 조합이 최적
- 복잡한 모델보다 단순한 모델이 해당 데이터셋에서 더 효과적
- 과적합 방지가 중요한 요소
- **Optuna 튜닝으로 리더보드 점수 +1.3% 향상 (0.0852 → 0.0863)**

### 향후 개선 방향
1. **더 넓은 탐색 범위**: num_factor 16~32 구간 추가 탐색
2. **다른 모델 시도**: SASRec, BERT4Rec 등 시퀀셜 모델
3. **앙상블**: ALS + SASRec 결과 결합
4. **Feature Engineering**: 시간대별 가중치, 세션 정보 활용
