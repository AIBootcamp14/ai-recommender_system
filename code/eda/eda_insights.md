## 0. 30년차 쇼핑몰 MD의 관점

### "이 데이터, 전형적인 신발 전문몰이네요"

**도메인 특성 파악:**
- **apparel.shoes가 35.5%** → 신발 중심 버티컬 커머스
- 4개월 데이터(11월~2월) → **시즌 전환기** (가을/겨울 → 봄)
- 가격대 중앙값 $79 → 중저가 캐주얼 신발 시장

### 핵심 비즈니스 인사이트

#### 1. "구매 전환율 0.02%? 이건 문제가 아니라 기회다"

```
view: 99.78% → cart: 0.20% → purchase: 0.02%
```

- 일반적인 이커머스 전환율 2-3% 대비 **매우 낮음**
- 하지만 이건 **"윈도우 쇼핑" 행동이 많다**는 의미
- **MD 전략**:
  - View 많은 상품 = 관심은 높지만 구매 망설임 → **가격 프로모션 대상**
  - Cart 담긴 상품 = 구매 직전 → **장바구니 리마인드 푸시**

#### 2. "respect 브랜드가 8.7% 1위? 가성비 브랜드 강세"

```
1위: respect (8.7%)
2위: sony (5.1%) - 전자제품?
3위: xiaomi (2.9%) - 전자제품?
```

- **의문점**: 신발몰인데 sony/xiaomi가 상위? → **크로스셀링** 또는 **가전 카테고리 확장**
- respect = 러시아 가성비 신발 브랜드 → **타겟 고객: 가격 민감층**
- **MD 전략**: 가격대별 추천 세그먼트 필요

#### 3. "55%가 1개만 보고 이탈? 랜딩 최적화 필요"

```
세션 길이 1: 55.3%
세션 길이 2-3: 23.1%
```

- **절반 이상이 1개 상품만 보고 떠남**
- 이건 추천 시스템 문제가 아니라 **UX/상품 상세페이지 문제**
- **MD 전략**:
  - 상세페이지에 "함께 본 상품" 강화
  - 첫 상품 클릭 시 바로 유사 상품 노출

#### 4. "주말에 30% 몰린다? 타이밍이 돈이다"

```
토+일: 31% (주말 집중)
피크: 14시-18시 (오후 쇼핑 타임)
```

- **금요일 저녁 ~ 일요일**: 핵심 구매 골든타임
- **MD 전략**:
  - 금요일 오후 신상품/프로모션 노출
  - 일요일 저녁 "내일 배송" 마감 푸시
  - 추천 모델도 **최근 7일 데이터 가중치 상향**

#### 5. "새 고객 52%? 신규 유입 채널이 활발하다"

```
Valid에서 새로운 사용자: 52.4%
```

- 기술팀은 "Cold-start 문제"라 하지만
- MD 관점에선 **"신규 고객 유입이 활발하다"**는 긍정 신호
- **MD 전략**:
  - 신규 고객 첫 구매 유도 프로모션
  - **베스트셀러/인기상품** 추천이 핵심
  - "다른 고객들이 많이 본 상품" 노출

#### 6. "상위 1% 상품이 25% 매출? Long-tail 전략 필요"

```
상위 1% 아이템 → 25.1% 상호작용
상위 20% 아이템 → 77.7% 상호작용
```

- **히트 상품 의존도 높음** → 리스크
- 하위 80% 상품은 거의 노출 안됨
- **MD 전략**:
  - **히트 상품**: 재고 확보, 유사 상품 개발
  - **롱테일 상품**: 추천에 다양성(Diversity) 반영
  - "이런 상품도 있어요" 섹션으로 발굴 기회

### 30년차 MD의 추천 시스템 조언

> "추천 시스템은 결국 **좋은 MD를 자동화**하는 것"

1. **신규 고객에겐 베스트셀러** (인기도 기반)
2. **재방문 고객에겐 개인화** (협업 필터링)
3. **구매 직전 고객에겐 대체재** (카테고리/가격대 유사)
4. **구매 후 고객에겐 보완재** (신발 샀으면 → 양말, 깔창)

### 추천 모델 적용 시 주의점

| 고객 세그먼트 | 비율 | 추천 전략 |
|-------------|------|----------|
| 신규 (Cold-start) | 52% | 인기상품, 베스트셀러 |
| 라이트 유저 (1-3회) | 35% | 카테고리 인기상품 |
| 헤비 유저 (10회+) | 13% | 개인화 협업필터링 |

## 0.1 MD 인사이트 기반 기술적 개선 방향

### 즉시 구현 가능 (1-2일)

| 우선순위 | MD 인사이트 | 기술적 구현 | 기대 효과 |
|---------|------------|------------|----------|
| **1** | 신규 고객 52%에겐 베스트셀러 | 인기도 기반 폴백 추가 | +3~5% |
| **2** | 구매/장바구니 가중치 차등 | event_type 가중치 (view=1, cart=5, purchase=10) | +1~2% |
| **3** | 최근 데이터 중요 | 시간 decay 가중치 적용 | +0.5~1% |

### 구현 코드 스니펫

#### 1. 인기도 기반 폴백 (Cold-start 대응)

```python
# 인기 아이템 Top 100 추출
popular_items = train_df.groupby('item_id').size().nlargest(100).index.tolist()

# Cold-start 사용자에게 인기 아이템 추천
def recommend_with_fallback(user_id, model_recommendations):
    if user_id not in known_users:
        return popular_items[:10]  # 인기 아이템 Top 10
    return model_recommendations
```

#### 2. event_type 가중치 적용

```python
# 현재: 모든 이벤트 동일 가중치
train_df["label"] = 1

# 개선: 이벤트별 차등 가중치
weight_map = {'view': 1, 'cart': 5, 'purchase': 10}
train_df["label"] = train_df["event_type"].map(weight_map)
```

#### 3. 시간 decay 가중치

```python
# 최근 데이터에 높은 가중치
max_time = train_df['event_time'].max()
train_df['days_ago'] = (max_time - train_df['event_time']).dt.days
train_df['time_weight'] = np.exp(-0.01 * train_df['days_ago'])  # 지수 감쇠
train_df['label'] = train_df['label'] * train_df['time_weight']
```

| **5** | 롱테일 상품 노출 | 추천 결과에 Diversity 반영 | +0.5~1% |

### 앙상블 전략 (MD 세그먼트 기반)

```python
def hybrid_recommend(user_id, als_recs, popular_items, user_history_count):
    """
    MD 전략: 고객 세그먼트별 다른 추천
    - 신규/라이트: 인기 상품 비중 높게
    - 헤비: 개인화 비중 높게
    """
    if user_history_count == 0:
        # 신규 고객: 100% 인기 상품
        return popular_items[:10]
    elif user_history_count <= 3:
        # 라이트 유저: 70% 인기 + 30% 개인화
        return merge_recommendations(popular_items, als_recs, ratio=0.7)
    else:
        # 헤비 유저: 30% 인기 + 70% 개인화
        return merge_recommendations(popular_items, als_recs, ratio=0.3)
```

### 예상 점수 향상 로드맵

```

[Phase 3] 하이브리드 앙상블    → 0.095 ~ 0.105 (+3~5%)

```

## 2. 핵심 인사이트

### 2.1 사용자 분포 - Long-tail 심각

```
상호작용 1회:    16.8%
상호작용 2-3회:  18.6%
상호작용 4-5회:  12.0%
상호작용 6+회:   52.6%
```

**인사이트:**
- 35% 사용자가 3회 이하 상호작용 → Cold-start 문제 심각
- 중앙값 6회, 평균 13회 → 활성 사용자와 비활성 사용자 편차 큼
- **전략**: 인기도 기반 폴백 필요, 사용자 세그먼트별 다른 모델 적용 고려

---

### 2.2 아이템 인기도 - 극심한 Long-tail

```
상위 1% 아이템 → 25.1% 상호작용
상위 5% 아이템 → 49.9% 상호작용
상위 10% 아이템 → 63.4% 상호작용
상위 20% 아이템 → 77.7% 상호작용
```

**인사이트:**
- 소수 인기 아이템에 상호작용 집중
- **전략**:
  - 인기도 가중치 적용 시 효과적일 수 있음
  - 다양성(Diversity) 고려한 Re-ranking 필요
  - 인기 아이템 추천만으로도 일정 점수 확보 가능

---

### 2.3 이벤트 타입 - View 중심

```
view:     99.78%
cart:      0.20%
purchase:  0.02%
```

**인사이트:**
- 구매/장바구니 데이터 매우 적음
- 현재 ALS는 모든 이벤트를 동일 가중치 처리
- **전략**:
  - event_type별 가중치 차등 적용 (purchase > cart > view)
  - 예: view=1, cart=5, purchase=10

### 2.6 Cold-Start 문제 (심각)

```
Valid에서 새로운 사용자: 52.4%
Valid에서 새로운 아이템: 11.5%
Cold-start 사용자의 상호작용 비율: 44.8%
```

**인사이트:**
- **절반 이상의 Valid 사용자가 Train에 없음** (매우 심각)
- 협업 필터링(ALS)으로는 이들 추천 불가
- **전략**:
  1. 인기도 기반 폴백 필수
  2. 카테고리/브랜드 기반 콘텐츠 필터링 추가
  3. Cold-start 사용자 탐지 후 별도 처리
