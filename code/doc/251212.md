### 1. 온톨로지 기반 추천 시스템 구현

#### 1.1 시스템 아키텍처
```
┌─────────────────────────────────────────────────────────┐
│  Stage 1: ALS 후보 생성 (Top 100)                       │
│  - factors=32, regularization=0.0215, alpha=7           │
└─────────────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────┐
│  Stage 2: 콘텐츠 기반 점수 (온톨로지 속성 매칭)          │
│  - 카테고리 매칭: 50%                                   │
│  - 브랜드 매칭: 30%                                     │
│  - 가격대 매칭: 20%                                     │
└─────────────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────┐
│  Stage 3: Co-view 기반 점수                             │
│  - 세션 내 함께 본 아이템 유사도                         │
│  - min_coview=2 필터링                                  │
└─────────────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────┐
│  Stage 4: 최종 점수 계산                                │
│  score = 0.8*ALS + 0.1*content + 0.1*coview            │
└─────────────────────────────────────────────────────────┘
```

- **브랜드**: 1,845개
- **가격대**: 5등급 (quintile 기반)

#### 1.3 Co-view 그래프
- Multi-item 세션: 1,291,657개
- Co-view pairs (min=2): 3,639,224개

### 4. 실험 3: Ontology v3 (클릭 횟수 가중치)

#### 가설
- 사용자가 같은 아이템을 여러 번 클릭하면 더 강한 관심 신호
- 클릭 횟수를 interaction matrix에 반영

#### 변경 사항
```python
# 변경 전 (binary)
interaction_matrix = csr_matrix(
    (np.ones(len(train_df)), (user_indices, item_indices)),
    shape=(len(users), len(items))
)

# 변경 후 (클릭 횟수 누적)
train_df['user_idx'] = train_df['user_id'].map(self.user_to_idx)
train_df['item_idx'] = train_df['item_id'].map(self.item_to_idx)
user_item_counts = train_df.groupby(['user_idx', 'item_idx']).size().reset_index(name='count')

interaction_matrix = csr_matrix(
    (user_item_counts['count'].values,
     (user_item_counts['user_idx'].values, user_item_counts['item_idx'].values)),
    shape=(len(users), len(items))
)
```

#### 결과
- **점수: 0.0868** (±0.00%)
- **효과 없음**: v2와 동일

#### 원인 분석
- 대부분의 사용자가 각 아이템을 1번만 클릭
- 데이터 특성상 view가 99.78%로, 같은 아이템 반복 조회가 드묾
- Interaction matrix: 5,943,059 unique pairs (중복 제거 후)

## 주요 발견

### 1. filter_already_liked_items의 중요성
```
filter=True:  0.0338 (-60.8%)
filter=False: 0.0868 (+0.58%)
```
- 이 대회에서는 **재방문 추천이 핵심**
- 기존에 본 아이템을 제외하면 성능 급락

### 2. 온톨로지 신호의 효과
- Content(카테고리/브랜드/가격) + CoView 가중치 0.2로 +0.58% 개선
- 순수 ALS(0.0863) → Ontology(0.0868)

### 3. 클릭 횟수 가중치는 효과 없음
- 대부분 1회 클릭이므로 binary와 동일한 결과
- 데이터 특성에 따라 다를 수 있음
