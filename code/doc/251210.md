- 탐색 범위:

## 실험 4: 낮은 num_factor 탐색

### 가설
- Optuna 1차 탐색에서 factor=32가 최적 (탐색 범위 32~128)
- 더 낮은 factor(8~32)가 더 좋을 수 있음

### 설정
- Optuna 탐색 범위 변경:
  - num_factor: 8~32 (step=4)
  - alpha: 1~20
  - iterations: 5~15

### Optuna 결과 (15 trials)
```
Best Parameters:
  num_factor: 8
  regularization: 0.003178
  alpha: 2
  iterations: 15

Best NDCG@10: 0.0224 (Validation)
```

### 리더보드 결과
- **점수: 0.0761** (-11.8%)
- **실패**: Validation NDCG는 높았으나 실제 점수 급락

### 원인 분석
1. **과소적합(Underfitting)**: factor=8은 너무 단순
2. **Validation-Test 분포 차이**: 시간 기반 분할과 실제 평가 조건이 다름
3. **alpha=2 너무 낮음**: 신뢰도 보정이 부족

### 교훈
- **Validation NDCG ≠ 리더보드 점수**
- 너무 단순한 모델은 실제 성능 저하
- factor=32가 이 데이터셋에 적합한 복잡도

### 파일
- `output_factor8_alpha2.csv`
