## 진행한 작업

### 1. MD Reranker v2: 가중치 튜닝

#### 목표
기존 MD Reranker v1 (0.1379)의 가중치를 조정하여 성능 개선 시도

#### 테스트한 설정들
```python
# v2_1: 카테고리 정확 매칭 강화
cat_exact=0.7, last_cat=0.5 → NDCG: 0.1369

# v2_2: 카테고리 매칭 최대화
cat_exact=1.0, last_cat=0.3 → NDCG: 0.1368

# v2_3: 구매 카테고리 페널티 강화
cat_exact=0.5, last_cat=0.5, purchased=0.5 → NDCG: 0.1375
```

#### 결과 분석
- **가중치 조정이 오히려 성능 하락**을 야기
- 기본 가중치(v1)가 이미 최적에 가까움
- 특정 규칙 강화가 다른 규칙과의 균형을 깨뜨림

### 2. MD Reranker v3: 고급 규칙 추가

#### 새로 추가된 규칙들

##### 1) 보완재 추천 (Complementary Items)
```python
COMPLEMENTARY_MAP = {
    'apparel.shoes': ['apparel.costume'],
    'apparel.shoes.keds': ['apparel.costume', 'apparel.shoes.slipons'],
    'apparel.shoes.slipons': ['apparel.costume', 'apparel.shoes.keds'],
    'apparel.shoes.boots': ['apparel.costume'],
    'apparel.costume': ['apparel.shoes', 'apparel.shoes.keds'],
}
```
- 신발 → 의류 (또는 반대) 추천 시 부스트
- 가중치: `complementary = 0.15`

##### 2) 반복 구매 패턴 (Repeat Purchase)
```python
# 2회 이상 구매한 카테고리
if cat_count >= 2:
    boost += weights['repeat_purchase']  # 0.2
elif cat_count == 1:
    boost += weights['repeat_purchase'] * 0.5  # 0.1
```

##### 3) 다양성 보장 (Diversity)
```python
# 같은 카테고리가 3개 이상이면 페널티
if same_cat_count >= 3:
    penalty += weights['diversity'] * 2  # 0.2
elif same_cat_count >= 2:
    penalty += weights['diversity']  # 0.1
```

##### 4) 스타일 그룹 다양성 (Style Diversity)
```python
STYLE_GROUPS = {
    'casual_shoes': ['apparel.shoes.keds', 'apparel.shoes.slipons', 'apparel.shoes.sneakers'],
    'formal_shoes': ['apparel.shoes.boots', 'apparel.shoes.loafers'],
    'athletic': ['apparel.shoes.sport'],
}
```

#### v3 결과
- **NDCG@10: 0.1378** (+0.29% from baseline)
- v1 (0.1379)보다 **0.01 낮음**
- Reranked: 631,193 / 638,257 users (98.9%)
- Diversity improved: 0 users (다양성 개선 효과 없음)

#### v3 실패 원인 분석
1. **보완재 규칙 한계**: 실제 데이터에서 shoes → costume 전환이 드묾
2. **다양성 페널티 역효과**: 유저가 실제로 같은 카테고리 선호하는데 페널티 부여
3. **도메인 특성**: apparel/shoes 위주로 크로스 카테고리 구매가 적음

## 주요 발견

### 1. MD Reranker의 한계
- 기본 가중치(v1)가 이미 최적에 가까움
- 추가 규칙이 오히려 성능을 저하시킴
- **0.1379가 MD Reranker의 실질적 상한선**으로 보임

### 2. 도메인 특성
- 24개 카테고리 모두 apparel/shoes 관련
- 크로스 카테고리 구매 패턴이 거의 없음
- 다양성 규칙이 효과를 발휘하기 어려운 구조

### 3. 가중치 튜닝의 비효율성
- Grid Search로 다양한 조합 테스트했으나 개선 실패
- 기본 모델의 직관적인 가중치가 가장 효과적
