## 12/14 진행 작업

### 2. Two-Stage Recommender (LightGBM Rerank)

#### 아키텍처
```
ALS 후보 생성 (Top 100)
    ↓
Feature Engineering
    - ALS 점수
    - 사용자 통계 (interaction count, category/brand 선호도)
    - 아이템 통계 (인기도, 가격대)
    - 시간 특성 (최근성, 활동 기간)
    ↓
LightGBM Reranking
    ↓
Top 10 추천
```

#### 결과
- **NDCG@10: 0.0697** (-19.3%)
- **실패 원인**: ALS의 좋은 점수를 LightGBM이 오히려 악화시킴
- 피처 엔지니어링이 추천 품질에 부정적 영향

### 3. Item2Vec Recommender

#### 아키텍처
```
Session → "문장"으로 취급
Item → "단어"로 취급
    ↓
Word2Vec (Skip-gram) 학습
    - vector_size=64
    - window=5
    - min_count=2
    ↓
ALS 0.7 + Item2Vec 0.3 가중 결합
```

#### 결과
- **NDCG@10: 0.0858** (-0.58%)
- **실패 원인**: Item2Vec 신호가 ALS보다 품질이 낮음
- 세션 기반 유사도가 구매 예측에 도움이 안 됨

### 5. Markov Chain Recommender (실행 중단)

#### 아키텍처
```
세션 내 아이템 전이 확률 학습
    - 세션별 (item_i → item_j) 전이 카운트
    - Transition Matrix 구축
    ↓
최근 5개 아이템 기반 전이 확률 계산
    ↓
ALS 0.7 + Markov 0.3 가중 결합
```

#### 실행 상황
- 학습은 완료
- 추천 생성: 11시간 이상 소요 (~80 users/sec)
- **중단**: 너무 느림

### 6. ALS Optimized v1 (NEW BEST!)

#### 핵심 개선 사항

##### 1) ALS 파라미터 강화
```python
als_params = {
    'factors': 64,        # 32 → 64 (더 풍부한 임베딩)
    'regularization': 0.01,
    'alpha': 10,          # 7 → 10
    'iterations': 20,     # 15 → 20
    'random_state': 42
}
```

##### 2) User Segmentation
```python
# 사용자 활동 수준별 분류
Heavy users (50+ interactions): 순수 개인화 (pop_weight=0.0)
Medium users (10-50): 약간의 인기도 (pop_weight=0.1)
Light users (<10): 높은 인기도 가중치 (pop_weight=0.2)
```

##### 3) Popularity Boost
```python
# 최종 점수 계산
final_score = (1 - pop_weight) * als_score + pop_weight * popularity_score
```

#### 결과
- **NDCG@10: 0.0922** (+6.8% from baseline, +5.7% from Ontology v4)
- 실행 시간: ~5분 (매우 빠름)
- **성공 요인**:
  - factors 증가로 더 정밀한 사용자/아이템 임베딩
  - User Segmentation으로 Cold/Light 사용자 처리 개선
  - 복잡한 하이브리드 대신 단순한 개선이 효과적

### als_optimized.py 핵심 로직

```python
class ALSOptimizedRecommender:
    def recommend(self, user_id: str, top_k: int = 10) -> list:
        # User Segmentation에 따른 인기도 가중치
        user_activity = self.user_interaction_count.get(user_id, 0)

        if user_activity >= 50:      # Heavy user
            pop_weight = 0.0         # 순수 개인화
        elif user_activity >= 10:    # Medium user
            pop_weight = 0.1         # 약간의 인기도
        else:                        # Light user
            pop_weight = 0.2         # 높은 인기도 가중치

        # ALS + Popularity 결합
        final_score = (1 - pop_weight) * als_score + pop_weight * pop_score
```
